Adaptive Palette Open demo

Documentation

Generate readable UI colors from one background.

Adaptive Palette is a small, framework-agnostic color engine for AI-generated dashboards, charts, cards, and dynamic UI surfaces.

What It Solves

Low contrast output

Generated UI often ships with text and chart lines that disappear on dark or light backgrounds.

Theme maintenance cost

Instead of manually maintaining separate light and dark palettes, provide one base color.

Unstable generated visuals

The same algorithm produces deterministic semantic tokens for text, borders, charts, and status tags.

Usage

import {
  applyPaletteToElement,
  createAdaptivePalette,
} from "./src/adaptive-palette.js";

const card = document.querySelector(".card");
const palette = createAdaptivePalette("#2B3548");

applyPaletteToElement(card, palette);

How It Works

The engine uses WCAG relative luminance and contrast ratio calculations. It chooses a readable direction, mixes colors from the background toward that direction, adjusts chart accents until they meet the target contrast, then exports the results as CSS custom properties.

It does not rely on mix-blend-mode as the primary strategy, because blend modes are useful visual effects but cannot reliably guarantee readability for dense charts and small UI text.

Deploy

This is a static project. On Vercel, use npm run build; the build creates the public/ output directory.
