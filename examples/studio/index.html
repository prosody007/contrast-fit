NOT A BLACK BOX

Inspect the decisions. Keep the output.

Seven translucent tokens are measured as one layer over the resolved background. Nesting them changes the result. Decorative border, grid, axis, fill, and bar tokens do not carry a non-text contrast guarantee.

      A small engine.
      Not another framework.

      Deterministic JavaScript. TypeScript declarations. ESM, CommonJS, and a classic browser build. Use the output in the stack you already have.

      FIT → APPLY → RENDER
      import { createContrastFit, applyPaletteToElement }
  from "contrast-fit";

const element = document.createElement("section");
element.textContent = "Your fitted interface";
document.body.append(element);
const palette = createContrastFit("#777777");
applyPaletteToElement(element, palette);
element.style.background = "var(--contrast-fit-bg)";
element.style.color = "var(--contrast-fit-text)";
// Charts also need palette.seriesStyles (dash + marker).
